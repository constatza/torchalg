# Cost-audit fixes: status

The work-depth / roofline / launch-count audit (`benchmarks/cost_model/`, measured at
`c3d65cb`) found executed work above the algorithmic minimum. This file tracks each finding,
the fix, and the evidence. The model and the `Cost:` docstring convention live in
`docs/implementations/cost-model.md`; per-module behaviour in each `README.md`.

Evidence rule: wall times on a shared machine are indicative only. A fix is accepted on
structural evidence (kernel launches, host synchronizations, bytes copied) and on equivalence
(identical factors or patterns, hierarchy sizes, PCG iteration counts, one-application
relative difference up to 1e-12 against the pre-change code).
